# 세책 — 일반 HTML · CSS · JavaScript 버전

기존 React 프로젝트와 별도로 만든 버전입니다. React, TSX, Vite 빌드가 필요 없습니다.
화면의 구조와 문구는 실제 `.html` 파일에 들어 있습니다. JS는 데이터 조회·저장과 반복되는 목록을 담당합니다.

## 실행

1. ZIP을 풀고 폴더 전체를 보관합니다. Windows 64비트 Node 실행 파일을 포함했습니다.
2. `세책 HTML 열기.cmd`를 두 번 클릭합니다. 서버 창과 브라우저가 열립니다.
3. 주소는 `http://127.0.0.1:5174/index.html`입니다. 서버 창은 열어 두세요.
4. 서버 창에서 Ctrl+C를 누르거나 창을 닫으면 종료됩니다.

HTML을 더블클릭해 file://로 여는 방식은 로그인/모듈/API 요청을 지원하지 않습니다. 위 실행 파일을 쓰면 됩니다.
다른 OS에서는 Node.js를 설치하고 `node server.mjs`를 실행하세요.

## VS Code에서 직접 수정

VS Code → 파일 → 폴더 열기 → 이 `sechaek-html` 폴더 선택.
HTML/CSS/JS를 수정하고 저장한 뒤 브라우저를 새로고침하면 바로 반영됩니다. 빌드 명령은 없습니다.
`index.html`의 `<h2>인기차트</h2>`를 바꾸면 홈 제목이 바뀝니다.
`room.html`의 `<h3>이번 달의 책</h3>`를 바꾸면 미니홈피 제목이 바뀝니다.

| 파일 | 담당 화면 |
|---|---|
| index.html | 홈, 인기차트, 프로필, 달력 |
| search.html | 검색, 8개 묶음 페이지 번호 |
| book.html | 책 상세, 가격 비교, 서재 등록, 리뷰 |
| library.html | 소장/찜 목록 |
| notebook.html | 비공개 노트, 독서 기록, 독서 정보 |
| room.html | 미니룸, 친구들, 이번 달의 책, 다이어리, 방명록 |
| shop.html | 아이템·세트 구매 |
| statistics.html | 월별 소비 통계 |
| explore.html | 독자 탐색·팔로우 |
| auth.html | 로그인·회원가입 |
| css/styles.css | 원래 기본 디자인 |
| css/readability.css | 글자·배치·반응형 보정 |
| css/html-version.css | HTML 버전의 추가 스타일; 새 CSS는 여기에 작성 권장 |
| js/페이지이름.js | 각 페이지의 버튼·데이터 동작 |
| js/common.js | 공통 로그인 상태·DB·프로필 창·카드 생성 |
| js/art.js | 방/상점 SVG 그림 |
| js/config.js | Supabase URL과 공개키만 저장 |
| server.mjs | 로컬 정적 파일 서버 + 공개 도서 조회 중계 |

공통 헤더와 프로필 대화상자는 각 HTML에 들어 있습니다. 공통 메뉴를 수정하면 다른 HTML에도 같은 수정이 필요합니다.
서버에서 받는 책 제목·목록은 HTML의 비어 있는 컨테이너에 JS가 채웁니다. 카드 구조는 `js/common.js`의 `card`, `cover`를 수정하세요.
`vendor/supabase.js`는 DB 연결용 라이브러리입니다. 수정하지 않아도 됩니다. React는 사용하지 않습니다.
`reference`는 기존 DB 설계 참고 자료이며 실행에 필요하지 않습니다. SQL을 다시 실행할 필요가 없습니다.

## 데이터와 기존 버전

- 기존 `sechaek-production` 소스와 배포 사이트는 변경하지 않았습니다.
- 같은 Supabase 프로젝트를 사용합니다. 새 버전에서 저장·삭제하면 기존 사이트에서도 같은 데이터가 변경됩니다.
- 로그인 세션은 HTML 버전용으로 분리했습니다. 기존 계정으로 로그인할 수 있습니다.
- 비공개 데이터는 기존 Supabase RLS로 보호됩니다. 노트 공개 설정은 없습니다.
- 인터넷이 있어야 DB·예스24·폰트가 연결됩니다. USB에 전체 DB가 저장되는 것은 아닙니다.
- 개발 서버는 127.0.0.1에만 연결됩니다. 외부 공개 배포는 하지 않았습니다.
- Live Server만으로는 `/api/catalog` 중계가 없으므로 예스24 검색이 안 됩니다. 제공된 실행 파일을 사용하세요.
- 포인트/완독 보상은 기존 서버 RPC·트리거를 사용합니다. 서버 함수와 키를 새로 만들 필요 없습니다.

## 교수님께 전달

폴더 전체 또는 `sechaek-html.zip`을 전달하세요. HTML/CSS 디자인을 직접 수정할 수 있습니다.
실데이터를 변경하지 않는 디자인 검토에는 비로그인 상태로 이용하세요.
수정본은 이 별도 HTML 버전에 반영됩니다. 기존 React 버전에 자동 반영되지는 않습니다.
